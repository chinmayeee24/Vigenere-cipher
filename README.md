# Vigenere-cipher
Vigenère Cipher Encryption Web App

A simple web-based implementation of the Vigenère Cipher Algorithm using HTML, CSS, and JavaScript.
This project allows users to encrypt and decrypt messages using a secret key.

Features
Encrypt plaintext using Vigenère Cipher
Decrypt ciphertext back to original text
Clean and responsive UI
Built with pure HTML, CSS, and JavaScript
Beginner-friendly cryptography project
Technologies Used
HTML5
CSS3
JavaScript
